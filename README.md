# Sistem Panen

## Deskripsi

Sistem Panen merupakan program Python sederhana yang digunakan untuk menghitung total hasil panen berdasarkan jumlah hasil panen dan harga per kilogram. Program ini juga dilengkapi dengan fungsi perhitungan diskon untuk mengetahui total harga setelah diskon.

## Cara Menjalankan Program

1. Pastikan Python telah terinstal pada komputer.
2. Buka terminal pada folder proyek `sistem-panen`.
3. Jalankan program dengan perintah:

```bash
python panen.py
```

4. Program akan menampilkan total hasil panen dan total harga setelah diskon.
